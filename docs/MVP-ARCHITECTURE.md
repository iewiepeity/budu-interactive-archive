# 《不渡》互動式網站 MVP

## 產品流程

1. `/`：看似正常的作家官網。停留、點擊「近期消息」後，頁面開始出現輕微異常。
2. `/works/stars`：《當群星墜落》作品頁。異常進度達標後，顯示不應存在的「繼續閱讀」。
3. `/read/prologue`：王城地牢序章。玩家以自己的身分和許哲維互動，選項改變好感度並解鎖徽章。
4. 自動扭曲：原話短暫顯現後被故障效果覆寫；NPC 對話只根據扭曲內容反應。
5. 全站右上角可開啟徽章櫃，顯示 10 枚徽章與解鎖狀態。

## 架構

- `app/`：Next.js App Router 頁面。
- `components/ArchiveProvider.tsx`：瀏覽器存檔、異常進度、好感度、徽章狀態。
- `components/StoryEngine.tsx`：資料驅動的選項式敘事與自動扭曲演出。
- `lib/content.ts`：作品、徽章與內容資料；未來新增章節不需重寫介面。
- 第一版使用 localStorage；未來可替換為帳號＋雲端存檔，狀態介面不變。

## 後續擴充點

- 章節 manifest、條件分支與多存檔槽。
- 徽章 `asset` 欄位可直接接入既有圖片素材。
- ARG 事件可由時間、造訪次數、徽章組合觸發。
- NPC 可見文本與玩家可見原話分層保存，避免後續劇情誤讀原話。
